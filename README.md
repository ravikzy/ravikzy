## 🧑‍💻 Quem sou eu

  Me chamo Cauê Ravik, estou cursando Desenvolvimento de Sistemas na EEEP Lúcia Baltazar, sou apaixonado em explorar possibilidades na área de TI. Estudo programação e construo projetos pra aprender na prática. Atualmente mantenho o foco entre **Java com orientação a objetos**, mas tenho um aprendizado já despertado em **Progamação Web** e **Structured Query Language(SQL)** e uma lógica para resolver problemas e criar sistemas!

## 🛠️ Stack

Já trabalhei com ferramentas como Bootstrap, Tailwind CSS, Next.js e React, desenvolvendo APIs integradas a banco de dados, com autenticação via JWT e Better Auth. Também construí aplicações com CRUD completo, cobrindo criação, leitura, atualização e exclusão de dados. Atualmente estou aprendendo Spring Boot pra ampliar minha atuação no back-end com Java.
